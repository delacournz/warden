# Warden

> `warden` CLI: machine-wide leasing of iOS sims, Android emulators, ports and app builds for agents/users. Bun + Turborepo monorepo. Apps in `apps/*`, shared packages in `packages/*`. Usage: [README.md](README.md). Plan: [docs/plans/wdn-warden-cli.md](docs/plans/wdn-warden-cli.md).

## Stack / Dependencies

- Bun (package manager, runtime, test runner)
- Turborepo (task orchestration)
- TypeScript (strict) via `@delacour/warden-tsconfig`
- Biome (lint + format) via `@delacour/warden-biome-config`
- prek (git hooks: biome check on commit, typecheck on push)

## Directory Structure

```
apps/
  cli/                # @delacour/warden — the `warden` binary (commands, Claude hook)
  docs/               # @delacour/warden-docs — Fumadocs + TanStack Start docs site (content/docs/*.mdx), :3210
  example/            # @delacour/warden-example — Expo + Delacour UI demo app; tester.army e2e flows run via `warden e2e example`
packages/
  core/               # @delacour/warden-core — lease store, allocation, device providers, build cache
  biome-config/       # shared Biome config (root.jsonc, react.jsonc)
  tsconfig/           # shared tsconfig (tsconfig.base.json, tsconfig.react.json)
  types/              # shared utility types (Result, AsyncResult, ok, err)
scripts/              # repo scripts (pre-commit biome)
```

## Key Patterns

- Every package/app `biome.jsonc` uses `"extends": "//"`; rules only live in `packages/biome-config/root.jsonc`.
- Packages extend `@delacour/warden-tsconfig/tsconfig.base.json` (composite); apps set `composite: false`.
- React code extends `tsconfig.react.json`.
- Errors returned as `Result` / `AsyncResult` discriminated unions from `@delacour/warden-types/result`.
- sqlite `BEGIN IMMEDIATE` (`store.transaction`) is the cross-process mutex — no lockfiles.
- Never shut down / erase / install on a device warden didn't create or lease (foreign = read-only).
- Only `@delacour/warden` is published to npm, from manifests generated by `apps/cli/scripts/npm-packages.ts` (node shim + per-platform binary packages). Every workspace `package.json` stays `private`.
- Side effects (`exec`, clock, pid liveness, stdin, spawn) are injected; tests use temp `WARDEN_HOME`.

## File Naming

| Type | Pattern |
|------|---------|
| Server fn module | `{domain}.api.ts` |
| Schema | `{domain}.schema.ts` |
| Client class | `clients/{domain}.ts` |
| Middleware | `{name}.middleware.ts` |
| Types | `{domain}.types.ts` |
| Hooks | `{domain}.hook.ts` |
| Tests | `{name}.test.ts(x)` colocated |
| Data/defaults | `{name}.data.ts` / `{name}.defaults.ts` |

## Rules

1. Route context for shared data — fetch in `beforeLoad`, read via `useRouteContext()`
2. TanStack Query is the cache — no global state stores
3. No barrel exports — import directly from source files
4. Colocate tests next to source
5. TDD — failing test first, run `bun test <path>`
6. No `any` — use discriminated unions
7. Biome for lint + format
8. prek hooks — biome on commit, typecheck on push

## Checklists

### Adding a package
1. `packages/{name}/package.json` named `@delacour/warden-{name}` with `fmt`/`lint`/`check`/`typecheck`/`test` scripts
2. `tsconfig.json` extending `@delacour/warden-tsconfig/tsconfig.base.json`
3. `biome.jsonc` with `"extends": "//"`, `"root": false`
4. `bun install`, then `bun run typecheck && bun run check`
