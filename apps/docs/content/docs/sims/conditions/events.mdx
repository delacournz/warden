<DemoTabs ids={["events"]} />

Two one-off events rather than states: nothing is held on the device afterwards.

```bash
warden ui push '{"aps":{"alert":"Order shipped"}}'
warden ui push ./payload.json
warden ui memory-warning
```

`--app <bundle>` names the app. `memory-warning` fails `E_APP_UNAVAILABLE` when the app is not running. From a spec: [Push and memory warnings in E2E tests](/docs/e2e/conditions/events).

| Command | iOS simulator | Android emulator |
|---|---|---|
| `push` | delivers the payload to the app (`simctl push`, needs `aps`, 4096 bytes max) | `E_UNSUPPORTED` |
| `memory-warning` | `E_UNSUPPORTED`: the `lowmemory` notification never reaches a UIKit app | `am send-trim-memory RUNNING_CRITICAL` to the running app |
